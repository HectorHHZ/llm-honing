## Limitations

- **One layout.** The segment has one native start and two rooms; the 10 reset groups are policy seeds, not layouts. Episodes are correlated within and across groups (every episode's first request is the same, so the weights evidence of all weights episodes is the same request); intervals over groups describe this sample only.
- **One fault instance per component**, each persistent for the whole episode. The fault-instance bootstrap therefore has three units.
- **Harness fault choice.** The brief's default (remove the `flip` option) is invalid for the integration's receiver (exact option set), so the #185 terrain omission was used. Laya's probabilities move little under it (about 0.01 at the first decision of the pilot), so harness episodes follow their clean partners' selections for long stretches while every request differs: Selections compared with the paired clean episode's, decision by decision (same seed, same start): harness: 2 of 10 identical to the end, the others first differ at model decision 0–123 (median 22); weights: 0 of 10 identical to the end, the others first differ at model decision 0–3 (median 0); controller: 0 of 10 identical to the end, the others first differ at model decision 1–15 (median 4).
- **Weights fault.** The alternate checkpoint selected `flip` in 1438/1500 (95.9%) of its model decisions, so weights episodes differ visibly in play as well as in probabilities.
- **Controls.** No-injection outcomes come from the seeded draws of the clean policy; a control is not a ground-truth label for chance.
- **Outcome effects.** `outcome_effect` is `not_established`; release-level score drop is untested; reference actions are unavailable.
- **Diagnosis model.** Codex CLI on a subscription: no immutable model revision and no per-call dollar cost; online replies can vary between runs.
- **Code after the collection.** After the 40 attempts were collected, the collector, adapter and helper code were changed only to resolve local locations at run time (`runtime.py`: `$VVVVVV_ASSETS`, `$VVVVVV_SDL_LIB`, `$FFMPEG`, `$EXP0_CODEX_BIN`) instead of absolute local paths, so that no published file names a local path or account; the collected bytes are unchanged, the manifests' code fingerprints refer to the collection-time files, and `pins.json` keeps the collection-time collector fingerprint. The runtime is tested on this Linux server only. A bundle built before the code is committed carries the placeholder revision `0`×40 and must be rebuilt with the real commit.
- **Not done here:** no upload, no training, no human review of decisive windows, no blind test set. The real diagnosis is pending (Codex usage limit).
