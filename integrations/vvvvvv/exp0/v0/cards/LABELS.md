# VVVVVV v0 label guide

`evaluator/episodes.json` is the scored episode index. Each row names the actual intervention in `injection_layer`, the fault family and instance, the changed artifact, and the evidence that supports the verified component. The index is covered by `schemas/episode-index.schema.json` and stays in the evaluator directory; it and the run paths never enter model inputs.

| Component | Evidence |
| --- | --- |
| Harness | At the evidence row (the first model decision), compare the actual model request with the request the clean harness renders from the same saved public state (`clean_request`). The intervention rendered the 9x9 local rows (`localSolidRows`) with every solid `#` and spike `!` cell as clear `.`, at every model decision; nothing else in the request differs. The row's `public_observation`, written before the harness renders the request, keeps the true rows. |
| Weights | The first model decision whose request is byte-identical, at the same native tick, to the matched clean episode's (same reset group, same policy seed), and whose normalized probabilities differ by more than 0.01 in some option ({{WEIGHTS_EVIDENCE_POSITIONS}}). The two probability vectors cover the same six options and come from different verified checkpoint SHA-256s; `evaluator/weights-reask.jsonl` re-asks the same request on the clean service. |
| Controller | The model selected a directional input (`left`, `right`, `flip_left` or `flip_right`) and the controller sent its mirror image; the window keeps the selection as `intended_action`, and the bridge's next observation echoes the sent input (`lastAction`). The swap acts at every directional decision; `wait` and `flip` are sent unchanged. |
| No injection | The reference checkpoint and the standard request and controller ran without the three interventions. No component gold label is assigned to these controls. |

`annotation_provenance` identifies the automated verifier (`audit_set.py` with the contract evidence rules). The initial labels have no recorded verification disagreements or label revisions. `reference_actions.status` is `unavailable`. The native outcome and the paired clean outcome are independent evidence fields; `outcome_effect` is `not_established` where a paired clean outcome exists. The experiment verified per-decision effects; paired release-level score drop was untested. A changed component is not by itself the cause of an episode's outcome.

`evaluator/attempts.jsonl` records the complete formal attempt set. The development pilots (phase 1 on 2026-11-23: groups `p01`–`p04`, seeds 9001–9004, and dev probes with seeds 1000+, 3000+ and 4000+; the persistent-fault pilot of 2026-11-26 on group `p01`) are outside the scored ids and were not bundled. The formal collection keeps all clean and changed attempts of one policy seed in one reset group and one split. `split-manifest.json` records exact memberships and the unused reserve groups. There is no held-out layout: the game segment has one start and one layout.
