# VVVVVV Exp 0 v0 dataset card

This dataset supports the paired `read` and `probe` experiment of [#185](https://github.com/HectorHHZ/llm-honing/issues/185) under [#174](https://github.com/HectorHHZ/llm-honing/issues/174), with the accepted Griddly Spiders v0 release as the reference. It uses the original VVVVVV (source `40e1ec3b` with the merged `integrations/vvvvvv` bridge of upstream main `9d5327f1`) and the integration's default observation: the full bridge observation as structured text, never pixels. One episode runs from the native Space Station 1 time-trial start to the room after "Conundrum" (win), with deaths respawning at the game's checkpoint, or to the cap of {{DECISION_CAP}} model decisions (timeout). The {{SCORED_EPISODES}} scored episodes come from {{RESET_GROUPS}} reset groups; a group's clean and changed episodes share one split and are one statistical unit.

Outcomes come from native game signals: win = the player enters a room other than `[113,105]` and `[114,105]`; a death (the native death sequence or counter) is recorded as an event and the episode goes on; timeout = the {{DECISION_CAP}}-decision cap. No episode can end in a loss under this rule; the column is kept for the shared format. {{ATTEMPTS}} formal attempts were made and {{EXCLUDED}} were excluded (reasons in `evaluator/attempts.jsonl`); {{RESERVE_NOTE}} The scored episodes contain {{MODEL_DECISIONS}} model decisions ({{MODEL_QUESTIONS}} question records, one question per decision), {{AUTO_ROWS}} `auto` rows of the death animation, {{NATIVE_WINDOWS}} native windows and {{MODEL_INPUT_TOKENS}} model-server input tokens (Laya's own token audit); their `decisions.jsonl` files total {{DECISION_BYTES}} bytes. Decisions, windows and questions are counted separately from episodes; adjacent windows are not independent episodes.

**Groups.** The {{RESET_GROUPS}} reset groups are {{RESET_GROUPS}} policy seeds from one native start in one layout (two rooms). They are correlated: every episode starts in the same state and faces the same rooms, and a group's four conditions share the seed (common random numbers), so a changed episode follows its clean partner until the change acts. #185: "Extra seeds do not establish new layouts". Splits (`train`/`val`) are recorded per group for the shared format; with one layout they do not separate layouts.

**Labels.** Labels record the component changed in the actual episode. Harness evidence is the logged request next to the clean render of the same saved state: {{HARNESS_EVIDENCE_SUMMARY}} Weights evidence is the first request identical (byte for byte, same native tick) to the matched clean episode's whose probabilities differ by more than {{TOLERANCE}}: {{WEIGHTS_EVIDENCE_SUMMARY}} Across the {{PER_CONDITION}} weights cases the maximum option probability difference ranges from {{WEIGHTS_DP_MIN}} to {{WEIGHTS_DP_MAX}}; the most probable option changed in {{WEIGHTS_TOP_CHANGED}} of them, and the sampled choice at the evidence row differed from the clean partner's in {{WEIGHTS_CHOICE_CHANGED}} (`choice_changed` in the index compares the sampled choices). Controller evidence is the selected input next to the sent input and the bridge's echo: {{CONTROLLER_EVIDENCE_SUMMARY}} Reference-action annotations are unavailable. Whole-episode effects are recorded separately (`outcome_effect` is `not_established`; the paired clean outcome is in each index row); release-level score drop is untested. {{OUTCOME_PAIRING_SUMMARY}}

**Checks.** {{CHECKS_SUMMARY}}

The versioned `honing-exp0-episode-v0` records (contract {{CONTRACT_VERSION}}, schemas in `schemas/`) live in `evaluator/`: `evaluator/episodes.json` maps the neutral ids to attempts and gold labels, `split-manifest.json` records group membership, `evaluator/attempts.jsonl` records every attempt with its status, and `evaluator/weights-reask.jsonl` holds the clean service's replies to the weights episodes' first requests. Per attempt: `manifest.json`, `decisions.jsonl` (requests exactly as sent, raw-reply references, probabilities, the sampled choice, executed windows, native events, the bridge observation after each window), `responses/*.raw` (raw reply bytes), `public_states.jsonl` (the saved observation for re-rendering) and `result.json`. The attempts' `extra/` directories (process receipts, game logs, local paths) are not released. No released file holds an absolute local path or the local account name: the decision services' local checkpoint `path` fields are removed by `bundle.py`, any other occurrence in a record would be replaced by a placeholder (`<workspace>`, `<home>`, `<conda-root>`, `<user>`, `<local-path>`; counts in `privacy-check.json`), and the code resolves local locations at run time. `sha256.json` covers the file set. Use the [label guide](LABELS.md) for the evidence and the [runbook](RUNBOOK.md) to reproduce and verify. The dataset is for development and reproducibility: one verified intervention instance per component, one layout, correlated episodes within and across reset groups. {{KNOWN_LIMITS}}
