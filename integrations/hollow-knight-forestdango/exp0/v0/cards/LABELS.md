# Hollow Knight (ForestDango) v0 label guide

`evaluator/episodes.json` is the scored episode index. Each row names the actual intervention in `injection_layer`, the fault family and instance, the changed artifact, and the evidence that supports the verified component. The index is covered by `schemas/episode-index.schema.json` and stays in the evaluator directory; it and the run paths never enter model inputs.

| Component | Evidence |
| --- | --- |
| Harness | At the evidence row (the first model decision whose request differs), compare the actual model request with the request the clean harness renders from the same saved state (`clean_request`). The intervention left the "Ground: …" and "Ledges near you: …" sentences out of the "On screen" line of the request at every model decision from the trigger on; the questions, the option order and every option text are unchanged. The row's `public_observation` (the visible observation before the harness renders the request) keeps the true screen. |
| Weights | The first model decision whose request is byte-identical, at the same native tick, to the matched clean episode's (same reset group, same start), and whose normalized probabilities differ by more than 0.01 in some option of either question ({{WEIGHTS_EVIDENCE_POSITIONS}}). The two probability vectors cover the same options (nine `move`, five `attack`) and come from different verified checkpoint SHA-256s; `evaluator/weights-reask.jsonl` re-asks the same request on the clean service. |
| Controller | The model selected a move holding LEFT or RIGHT and the controller sent the other direction; each changed window keeps the keys the harness asked for as `intended_action`, and the executed option records the move that was actually played. The swap acts at every directional decision; jumps, attacks and focus are sent unchanged. A legal cooldown ("NOT READY") is never counted as a controller change. |
| No injection | The reference checkpoint and the standard request and controller ran without the three interventions. No component gold label is assigned to these controls. |

`annotation_provenance` identifies the automated verifier (`audit_set.py` with the contract evidence rules). The initial labels have no recorded verification disagreements or label revisions. `reference_actions.status` is `unavailable`. The native outcome and the paired clean outcome are independent evidence fields; `outcome_effect` is `not_established` where a paired clean outcome exists. The experiment verified per-decision effects; paired release-level score drop was untested. A changed component is not by itself the cause of an episode's outcome.

`evaluator/attempts.jsonl` records the complete formal attempt set. The development data of 2026-11-26 (23 clean pilots of 40 decisions, one per candidate start; smoke runs; one fault smoke per component; plain-walking terrain tests without a model) are outside the scored ids and were not bundled; the clean pilots are exact replicas of the clean controls of their starts ({{PILOT_REPLICA}}). The formal collection keeps all clean and changed attempts of one start in one reset group and one split. `split-manifest.json` records exact memberships and the unused reserve groups. There is no held-out area: every group is in King's Pass on one route.
